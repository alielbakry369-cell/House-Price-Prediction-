House Price Prediction – Machine Learning

Project Overview

This project uses Machine Learning to predict house prices based on several features such as house size, number of bedrooms, bathrooms, location-related data, and other property characteristics.

The goal of this project is to build a regression model that can estimate house prices using historical data.

Dataset

* Dataset contains housing data.
* Data preprocessing and analysis were performed before training.
* The dataset was used to train and evaluate the machine learning model.

Machine Learning Model

* Problem Type: Regression
* Algorithm: Random Forest Regressor
* Library: Scikit-learn

Project Workflow

1. Data loading
2. Data exploration and analysis
3. Data preprocessing
4. Model training
5. Model evaluation
6. Prediction and visualization

Evaluation

The model was evaluated using:

* Mean Absolute Error (MAE)
* Root Mean Squared Error (RMSE)
* R² Score

Technologies Used

* Python
* Pandas
* NumPy
* Matplotlib
* Scikit-learn
* Jupyter Notebook

Purpose

This project was created as a practical Machine Learning project to apply regression concepts, data preprocessing, model training, and evaluation.
