House Price Prediction Using Machine Learning

Project Overview

This project aims to predict house prices using Machine Learning techniques. It uses a regression model to estimate house prices based on different numerical features.

Dataset

The dataset contains 20,000 records with multiple numerical features used to train and evaluate the prediction model.

Technologies Used

* Python
* NumPy
* Pandas
* Matplotlib
* Seaborn
* Scikit-learn
* Jupyter Notebook

Machine Learning Approach

This project follows a supervised learning approach using Regression to predict continuous house prices.

Model Evaluation

The model performance is evaluated using:

* Mean Absolute Error (MAE)
* Root Mean Squared Error (RMSE)
* R-squared (R²)

Results

The model achieved an R² score of approximately 0.970 in the reported experiment.

How to Run

1. Download or clone this repository.
2. Install the required Python libraries.
3. Open the Jupyter Notebook.
4. Make sure the dataset Excel file is in the same directory as the notebook.
5. Run the notebook cells in order.

Project Files

* House-Price-Prediction-ML.ipynb: Jupyter Notebook containing the code and analysis.
* house_price_regression_20000.xlsx: Dataset used for training and testing.
* README.md: Project documentation.
